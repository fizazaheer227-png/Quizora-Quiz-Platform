# QUIZORA

### Play. Compete. Climb.

Quizora is an interactive quiz and assessment platform designed for both students and educators. It combines traditional quizzes, AI-assisted study-material quizzes, custom test creation, leaderboards, performance tracking, and quiz analytics in one platform.

The goal of Quizora is to make learning more interactive while also giving educators a simple way to create and conduct assessments.

---

## Key Features

### Play a Quiz
Users can challenge themselves using built-in quizzes across multiple categories:
- Technology
- Science
- General Knowledge
- Movies & Entertainment
- Sports
- Coding

Users can select the difficulty level, number of questions, and quiz mode.

### Quiz From My Notes
Students can upload their own study material and generate personalized quizzes based on their notes.

Supported formats include:
- PDF
- DOCX
- TXT
- Images

Students can customize the difficulty, number of questions, question type, and quiz mode. Quizora can also identify weak areas based on incorrect answers to help students focus their revision.

### Create a Quiz
Faculty members, teachers, and quiz organizers can create their own assessments.

Creators can:
- Create questions manually
- Generate questions from study material using AI
- Add MCQ and True/False questions
- Edit generated questions
- Configure quiz settings
- Set time limits
- Shuffle questions and answers
- Set passing scores
- Publish quizzes

Published quizzes can generate a unique Quiz Code that participants can use to join.

### Join With Quiz Code
Students can enter a Quiz Code to access a quiz created by a faculty member or quiz organizer.

The test interface includes question progress, timers, answer tracking, submission, scores, percentages, and performance results.

### Leaderboard
Quizora includes a competitive leaderboard displaying:
- Rank
- Player
- Score
- Accuracy
- Quizzes played
- Best streak

Category-specific leaderboards are also supported.

### Performance Analytics
Users can track:
- Total quizzes completed
- Questions answered
- Average accuracy
- Total points
- Best streak
- Recent activity
- Performance by category

### Faculty Analytics
Quiz creators can view:
- Number of attempts
- Average score
- Highest and lowest scores
- Completion time
- Student-wise results
- Question-wise performance

### Achievements
Users can unlock achievements for completing quizzes, earning perfect scores, maintaining streaks, exploring categories, and reaching leaderboard milestones.

## Quiz Modes

**Classic Mode** — Complete the quiz without an individual countdown timer.

**Timed Mode** — Answer questions while working against the clock.

Bonus points can also be awarded for maintaining correct-answer streaks.
